## Run locally

```powershell
git clone https://github.com/fadymagdy159/portfolio-website.git
cd portfolio-website
python -m http.server 8000
```

Open `http://127.0.0.1:8000/`. This static site does not require a backend or package installation. External fonts and interface libraries require an internet connection.
